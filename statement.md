# Project Statement

## Problem Statement

College students often have several small academic tasks to remember, such as studying a topic, completing an assignment or preparing for a practical. A simple task list can help the student record and track these activities.

The problem is to design a small command-line To-Do List in Python that allows a student to add, view, search, complete and delete tasks while demonstrating the algorithms and data structures covered in the course.

## Scope

The project is a local, menu-driven command-line application.

It includes:

- Task creation
- Task display
- Task completion
- Task deletion
- Task searching
- Basic task reporting
- Fundamental algorithm demonstrations

The application stores tasks only while the program is running. Persistent storage is intentionally outside the project scope because file/database concepts are not part of the supplied syllabus.

## Target Users

The primary target user is a college student who wants a simple command-line academic task list.

## High-Level Features

1. Add a new task.
2. View all tasks.
3. Mark a task as completed.
4. Delete a task.
5. Search for a task.
6. View a task report.
7. Practice selected fundamental algorithms through the Algorithm Lab.
